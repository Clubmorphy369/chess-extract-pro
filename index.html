ChessExtract Pro

Herramienta profesional para extraer tableros de ajedrez de imágenes y generar ejercicios en PDF

Instrucciones:

  1. Sube una o más capturas de pantalla que contengan tableros de ajedrez
  2. Navega entre las imágenes usando los botones anterior/siguiente
  3. Ajusta el recuadro para seleccionar solo el tablero
  4. Guarda el recorte como plantilla si deseas aplicarlo a imágenes similares
  5. Guarda el tablero recortado
  6. Repite el proceso para agregar más tableros (máximo 6 por página PDF)
  7. Genera y descarga el PDF con tus ejercicios en tamaño A4
